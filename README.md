# NOVA FCT Thesis Experimental Pipeline

This repository contains the source-code artifacts, network datasets and archived experimental results produced for the experimental pipeline and baseline comparisons.

## Repository Structure

- [`src/`](./src/) — Source-code artifacts implementing the experimental pipeline and baseline comparisons.
- [`networks/`](./networks/) — Generated synthetic networks and preprocessed real-world networks used in the experiments.
- [`archive/`](./archive/) — Archive of the experimental results.
