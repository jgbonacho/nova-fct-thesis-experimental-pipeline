# Source Code

This folder contains the source-code artifacts developed for the experimental study, including the experimental implementations and their associated tests.

## Folder Structure

- [`pipeline/`](./pipeline/) — Source code implementing the experimental pipeline and baseline comparisons.
    - [`__main__.py`](./pipeline/__main__.py) - Entry point for executions.
    - [`config/`](./pipeline/config/) - Configuration folder of the executions.
- [`tests/`](./tests/) — Tests for the experimental source code.
- [`plots/`](./plots/) — Source code for generating the plots and tables used to report the experimental results.
